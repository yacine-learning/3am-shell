# 3am shell

An on-call terminal game: investigate a broken Ubuntu server and its Docker containers by typing real shell commands, then answer a question to close each incident.

- 8 training lessons: pwd, ls, grep, find, df, du, ps, ss, curl, pipes, redirection, sudo, docker
- 17 on-call missions of increasing difficulty, each one unlocking the next
- Hints and wrong answers cost points; a debrief shows how a pro would have done it

Everything runs in the browser from a single `index.html` (simulated bash + Docker, no backend). Progress is saved in your browser's local storage. All people, companies, logs and IP addresses are fictional (IPs use documentation ranges).

**Play:** https://yacine-learning.github.io/3am-shell/
